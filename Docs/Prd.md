# 🧾 Product Requirements Document (PRD)
## Product Name: DoctorGPT

---

## 🎯 Objective
DoctorGPT is an AI-powered health assistant that provides:
- Preliminary health insights based on symptoms
- Safe home remedies (if applicable)
- Doctor recommendations in India

⚠️ It does NOT replace professional medical advice.

---

## 👥 Target Audience
- General public
- Students
- Working professionals
- Elderly users (simple UI required)

---

## 🧩 Core Problem
Users often:
- Google symptoms and get confused
- Don’t know which doctor to consult
- Delay treatment due to uncertainty

---

## 💡 Solution
DoctorGPT provides:
- Structured AI response
- Severity detection
- Clear next steps

---

## 🔑 Key Features

### 1. Input System
- Age
- Gender
- Symptoms (text)
- Duration

### 2. AI Analysis
- Condition prediction
- Severity classification
- Safe remedies

### 3. Doctor Recommendation
- Specialist suggestion
- Top doctors (India)

### 4. Safety Layer
- Warnings
- Emergency detection
- Disclaimer

---

## 🚫 Constraints
- No prescriptions
- No diagnosis claims
- Must include disclaimer

---

## 📊 Success Metrics
- User engagement
- Accuracy (perceived)
- Session duration
- Doctor click-through rate

---

## 🧱 MVP Scope
- Basic UI
- AI integration
- JSON output parsing
- Static doctor data

---

## 🚀 Future Scope
- Real doctor APIs (Practo)
- Chat-based follow-ups
- Medical report upload
- AI memory
